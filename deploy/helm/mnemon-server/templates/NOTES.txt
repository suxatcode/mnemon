Max insights (per principal, personal layer): {{ .Values.maxInsights }}

Issue a user (no restart required):

  kubectl exec -it deploy/{{ include "mnemon-server.fullname" . }} -- \
    mnemon-server user issue \
      --principal alice@team --role user \
      --server {{ include "mnemon-server.fullname" . }}:{{ .Values.service.port }} \
      --jwt-key /config/jwt.key \
      --out -

Then on the client: mnemon auth login --default invite.json

Production AWS: use values-rds.yaml with postgresql.enabled=false and an RDS DSN secret.
Users live in Postgres (`principals` and `issued_tokens` tables). Adding a user is an INSERT plus JWT issue; no pod restart.
